EnumWindowByProcess

函数简介:

按进程名枚举窗口(如多开游戏取全部实例), 语义同 EnumWindow。

函数原型:

EnumWindowByProcess(process_name, title, class_name, filter_)

参数定义:

process_name 字符串 【必传】: exe 名, 如 "game.exe"(可不带后缀)
title 字符串 【必传】: 标题包含词
class_name 字符串 【必传】: 类名包含词
filter_ 整形数 【必传】: 同 EnumWindow

返回值:

字符串: "hwnd,hwnd,..."

示例:

hs = dm.EnumWindowByProcess("game.exe", "", "", 0)
← 目录
