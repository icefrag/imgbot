go

函数简介:

走到目标界面。到达 True; 总超时/停止安静 False(失败语义调用方交代); 迷路抛 LostError(黑屏/掉登录, 需重登); 无可达路径/未注册 ValueError(建图错误启动即大声)。边验证失败与迷路现场自动截图留痕。

函数原型:

nav.go(name, timeout=120, stop=None)

参数定义:

name 字符串 【必传】: 目标界面名
timeout 浮点数 【可选, 默认 120.0】: 总超时秒数
stop 对象 【可选, 默认 None】: threading.Event 或无参回调, 触发即安静退出

返回值:

bool

示例:

ok = nav.go('dungeon', timeout=60)
← 目录
