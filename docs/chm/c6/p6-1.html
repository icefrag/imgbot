screen

函数简介:

注册界面: 一屏一锚点。同名重注册=更新锚点(不用改边表); 注册序即 where 扫描序, 判别力强的锚点先注册。

函数原型:

nav.screen(name, anchor, region=None, threshold=None)

参数定义:

name 字符串 【必传】: 界面名(任务代码/go 用它引用)
anchor 字符串 【必传】: 锚点模板名(nav/屏名.png 约定)
region 元组 【可选, 默认 None】: (x1,y1,x2,y2) 位置固定 UI 必须限矩形
threshold 浮点数 【可选, 默认 None】: 相似度, None=库默认 0.85
