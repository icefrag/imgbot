FindColor

函数简介:

区域找色。

函数原型:

FindColor(x1, y1, x2, y2, color, sim=1.0, dir=0)

参数定义:

x1 整形数 【必传】: 搜索区域
y1 整形数 【必传】: 搜索区域
x2 整形数 【必传】: 搜索区域
y2 整形数 【必传】: 搜索区域
color 字符串 【必传】: RRGGBB 或 RRGGBB-DRDGDB
sim 浮点数 【可选, 默认 1.0】: 相似度(经容差换算)
dir 整形数 【可选, 默认 0】: 方向(0 首个/其他取末个)

返回值:

元组: (x, y); 未找到 (-1, -1)

示例:

x, y = dm.FindColor(0, 0, 500, 500, "FF0000-000010", 1.0)
