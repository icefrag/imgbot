FindPic

函数简介:

模板匹配找图。pic_name 支持多模板(竖线分隔, 按序取首个命中)。

函数原型:

FindPic(x1, y1, x2, y2, pic_name, delta_color, sim=0.9, dir=0)

参数定义:

x1 整形数 【必传】: 搜索区域(客户区坐标, 尽量小别全屏)
y1 整形数 【必传】: 搜索区域(客户区坐标, 尽量小别全屏)
x2 整形数 【必传】: 搜索区域(客户区坐标, 尽量小别全屏)
y2 整形数 【必传】: 搜索区域(客户区坐标, 尽量小别全屏)
pic_name 字符串 【必传】: 模板文件名(带 .png), 相对 SetPath 目录; 多模板写 a.png|b.png
delta_color 字符串 【可选, 默认 000000】: 色偏容差 RRGGBB-DRDGDB(保留位)
sim 浮点数 【可选, 默认 0.9】: 相似度阈值 0~1, 默认 0.9; 禁止降阈值硬凑
dir 整形数 【可选, 默认 0】: 搜索方向(保留, 现只支持 0)

返回值:

元组: (模板序号, x, y); 未找到 (-1, -1, -1)

示例:

idx, x, y = dm.FindPic(0, 0, 800, 600, "按钮.png", "000000", 0.9)
