FindColorEx

函数简介:

同 FindColor, 返回所有命中 x,y|x,y 字符串。

函数原型:

FindColorEx(x1, y1, x2, y2, color, sim, dir)

参数定义:

x1 整形数 【必传】: 搜索区域
y1 整形数 【必传】: 搜索区域
x2 整形数 【必传】: 搜索区域
y2 整形数 【必传】: 搜索区域
color 字符串 【必传】: 颜色串
sim 浮点数 【可选, 默认 1.0】: 相似度
dir 整形数 【可选, 默认 0】: 方向

返回值:

字符串

示例:

ret = dm.FindColorEx(0, 0, 500, 500, "FF0000", 1.0)
