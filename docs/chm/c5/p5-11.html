wait_stable

函数简介:

等区域画面静止(连续 frames 帧哈希一致 = 加载完成)。注意: 逐字节全等, 区域内有轻微动画会永远不稳。

函数原型:

ops.wait_stable(region, timeout=30, interval=0.3, frames=5, stop=None)

参数定义:

region 元组 【必传】: 监测矩形
timeout 浮点数 【可选, 默认 30】: 超时秒数
interval 浮点数 【可选, 默认 0.3】: 采样间隔秒(默认 0.3s 采一次)
frames 整形数 【可选, 默认 5】: 连续一致帧数(默认 5, 最快约 1.2s 判稳)
stop 对象 【可选, 默认 None】: 停止信号

返回值:

bool

示例:

ok = ops.wait_stable((100, 100, 800, 600), timeout=20, frames=3)
