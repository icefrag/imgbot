wait_pic

函数简介:

等图出现。模板=SetPath 目录下 PNG(四角同色自动键控成透明模板)。

函数原型:

ops.wait_pic(pic, region=None, timeout=30, interval=0.4, threshold=None, stop=None)

参数定义:

pic 字符串 【必传】: 模板文件名, 如 领取.png
region 元组 【可选, 默认 None】: (x1,y1,x2,y2) 固定 UI 必须限矩形
timeout 浮点数 【可选, 默认 30】: 超时秒数, 超时返 None 并自动留痕
interval 浮点数 【可选, 默认 0.4】: 轮询间隔秒
threshold 浮点数 【可选, 默认 None】: 相似度, None=库默认 0.85
stop 对象 【可选, 默认 None】: 停止信号

返回值:

(x, y, 分数) 或 None

示例:

hit = ops.wait_pic("主界面.png", region=(0, 0, 300, 200), timeout=15)
