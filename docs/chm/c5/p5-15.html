swipe_find

函数简介:

列表滚动查找: 逐屏拖动, 每屏找一次。

函数原型:

ops.swipe_find(pic, direction, region=None, timeout=30, threshold=None, stop=None)

参数定义:

pic 字符串 【必传】: 目标模板名
direction 字符串 【必传】: up / down / left / right
region 元组 【可选, 默认 None】: 找图区域(拖动恒在窗口中央)
timeout 浮点数 【可选, 默认 30】: 总超时秒数
threshold 浮点数 【可选, 默认 None】: 相似度
stop 对象 【可选, 默认 None】: 停止信号

返回值:

(x, y) 或 None

示例:

xy = ops.swipe_find("好友头像.png", "up", timeout=20)
