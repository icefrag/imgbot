wait_color

函数简介:

等色出现 —— 色比图快一个量级(转圈/倒计时)。

函数原型:

ops.wait_color(color, region=None, timeout=30, interval=0.4, stop=None)

参数定义:

color 字符串 【必传】: RRGGBB 或 RRGGBB-DRDGDB
region 元组 【可选, 默认 None】: 搜索矩形
timeout 浮点数 【可选, 默认 30】: 超时秒数
interval 浮点数 【可选, 默认 0.4】: 轮询间隔秒
stop 对象 【可选, 默认 None】: 停止信号

返回值:

(x, y) 或 None

示例:

xy = ops.wait_color("FF0000", region=(0, 0, 300, 200), timeout=5)
